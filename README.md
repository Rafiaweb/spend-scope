# SpendScope

SpendScope is an AI spend audit tool for startups that helps teams understand and reduce their monthly AI tool costs.

It analyzes tools like ChatGPT, Claude, and GitHub Copilot and suggests cost-optimized plans.

🔗 Live: https://spend-scope-gamma.vercel.app/

## Decisions
- Used Next.js for fast deployment and routing
- Used localStorage instead of backend for MVP speed
- Focused on UX first, backend later
- Tailwind CSS for rapid UI design
- Kept audit logic rule-based for transparency
