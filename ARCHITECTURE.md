# Architecture

## Stack
- Next.js (Frontend + routing)
- React (UI)
- Tailwind CSS (styling)

## Flow
User Input → runAudit() → Pricing Logic → Result UI → Save (localStorage)

## Why this stack
Fast development, easy deployment, good for MVP.
